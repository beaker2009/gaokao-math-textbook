# 《猴子也能看懂的高考数学到强基高联》

本仓库保存整套教材的 Markdown 源稿、统一样式、构建脚本与最终 PDF。

## 分层标记

- **★ 高考核心**：所有读者必须掌握。
- **◆ 强基/自招常考**：在高考基础上加强结构识别与证明。
- **▲ 高联二试重点**：强调严谨证明、构造与方法迁移。
- **☆ 拔高选学**：超出主线但有助于建立高观点。

正文内部另用三个学习层级：

1. **基础层**：直觉、概念、最小可用方法。
2. **提高层**：典型模型、多方法比较、参数与综合。
3. **超越层**：证明、推广、竞赛视角及与后续数学的连接。

## 每章固定结构

学习地图 → 诊断测试 → 各节正文（直觉/定义/方法/例题/易错/训练）→ 方法树 → 分层习题 → 提示与答案 → 章末复盘。

## 构建

源稿优先使用 Markdown + LaTeX 数学公式。安装 Pandoc 与 XeLaTeX 后运行：

```bash
python3 scripts/lint_markdown.py
bash scripts/build.sh
```

构建脚本会先检查控制字符、数学分隔符和重复的 LaTeX 反斜杠。单章文件位于 `parts/`；合订源稿生成至 `build/book.md`，PDF 生成至 `dist/猴子也能看懂的高考数学到强基高联.pdf`。若本机未安装 Pandoc 或 XeLaTeX，脚本仍会生成合订 Markdown，并明确报告缺失的工具。
